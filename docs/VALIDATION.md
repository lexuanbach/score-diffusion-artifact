This record does not claim that every transitive package is necessary or that a fresh Linux/CUDA environment was validated.

Source adaptation is limited to artifact output paths, a JSON export of the original Figure 1 data script, and new packaging/reproduction scripts. `docs/source-snapshot.json` lists the original numerical-source hashes. `docs/package-files.json` lists public-package hashes, and data/logit file manifests cover the release archives. The snapshot checksum does not claim every original result was generated by the current source revision. Some historical result rows carry `code=nogit` from runs without a git checkout.

The public package excludes local sync/deployment scripts, tokens, private server addresses, local review documents, manuscript PDF and LaTeX source. The supplementary PDF is included by the author's instruction.
